# Backend: статус первой реализации

Дата: 24.10.2026. Это статус локальной реализации, не подтверждение развёртывания на VPS.

## Реализовано

- FastAPI: meta, история, сравнение, liveness/readiness, OpenAPI.
- SQLite/WAL, Alembic, справочники 85 регионов из источника и 3 видов топлива; устойчивые ID, явные территориальные срезы областей без автономных округов.
- Сбор каталога и документов Росстата; последовательная загрузка, повторы, allowlist адресов/redirect, ограничения размера/времени/диска.
- Отдельная настройка TLS-исключения только для Росстата по решению пользователя.
- Версии данных, атомарная публикация, проверка изменений/скачков, ручное одобрение, откат, журнал запусков, общий lock записи.
- Сравнение на общие даты, пропуски, точные проценты, дата и источник каждой цены.
- Экспорт JSON для резервного режима frontend.
- Согласованный backup SQLite с оригиналами; хранение семи последних копий.
- Шаблоны systemd API/сборщика/backup, таймеры, ограничения ресурсов, Caddy и ротация логов.
- CI-конфигурация Linux/Python 3.12 и 3.14. Удалённый CI пока не запускался.

## Проверенные данные

- 13 недельных публикаций, наблюдения с **27.07.2026 по 19.10.2026**.
- 3 315 цен: 85 регионов × 3 вида топлива × 13 дат.
- В текущем наборе нет пропусков. 29 срабатываний порога скачка 10% сверены с оригиналами; они являются значениями источника и сохранены, а не сглажены.
- Все 3 315 значений дополнительно сверены с отдельными ячейками исходных таблиц; проверены SHA-256 13 сохранённых документов. Сводные строки и перекрывающиеся агрегаты исключены.
- Первая полная версия опубликована локально через операторский CLI. Отчёт: `data-audit.json`. БД и оригиналы — `backend/data`, резервный JSON — `backend/exports/snapshot.json`; эти рабочие файлы не включаются в Git.
- До расширения географии реальный повторный сбор последних 8 публикаций вернул `no_changes`; после расширения история заново обработана из сохранённых оригиналов с проверкой контрольных сумм.

## Проверки

- 37 pytest-тестов прошли на Windows/Python 3.14. Файловая SQLite, настоящие миграции, реальный исходный HTML плюс явно синтетические граничные случаи; проверены особые названия, отсутствие региона и разделение агрегатов.
- Ruff check/format и pip check пройдены; Alembic check не обнаружил расхождений схемы.
- Реальный запуск Uvicorn на временном localhost-порту: health, meta, prices и comparison вернули 200.
- После расширения: 30 HTTP-запросов, 10 параллельных клиентов, локальный p95 около 142 мс. Подтверждены ответы по новым регионам, сравнение и сохранность старой версии с шестью регионами; отчёт — `regions-http-smoke.json`. Это не измерение Linux VPS и не проверка соседства с VPN. Прежний отчёт `http-smoke.json` сохранён как результат первого этапа.
- Есть предупреждение upstream Starlette о будущем изменении тестового HTTP-клиента; оно не привело к сбоям тестов.
