# Статус frontend

24.10.2026. Проверено локально на Windows, Node.js 22.22.2 и Chrome.

- Обзор, поиск региона, ДТ/АИ-92/АИ-95, периоды 4/8/12 недель и свои даты.
- Графики с реальными датами, разрывами и таблицей точных значений.
- Сравнение до трёх регионов на общие даты; отдельные состояния одной точки и отсутствия данных.
- Калькулятор партии или парка до 20 строк, своя цена и точное округление HALF_UP.
- Параметры и версия в URL, отмена старых запросов, проверка контрактов Zod.
- Резерв целого экрана; другая закреплённая версия требует явного выбора. Введённый расчёт сохраняется при переключении источника.
- Страница источников, ссылки на публикации, территориальные срезы и предупреждения об устаревании.
- Адаптация проверена на 360 px; таблицы прокручиваются внутри блоков.

Проверки: 36 Vitest-тестов, 9 Playwright-сценариев, TypeScript и production-сборка. В браузере проверено реальное API, а также управляемые отказы и неверные ответы. Общие контрольные примеры `shared/comparison-cases.json` проверены Python API и резервным адаптером.

Резерв: версия `2bd2f525aca0456890c427d004770b62`, 3 315 наблюдений за 27.07–19.10.2026. Несжатый JSON — 527 589 байт; JS production-сборки — около 798 КБ (240 КБ gzip), CSS — 39 КБ (9 КБ gzip); шрифты поставляются локально. Целевые показатели времени на ограниченной сети ещё не измерены.

Vercel и VPS не развёрнуты. CI-конфигурация добавлена; её результат проверяется отдельно в GitHub Actions. Следующий этап — HTTPS API на VPS, подключение Vercel и отчёт для конкурса.
